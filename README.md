# tools

跨项目的**独立小工具**集合。跟 CBAP / CPNC 协议族**没有关系**，也不依赖主仓任何代码——
放在这个组织下只是因为作者是同一个。

| 工具 | 做什么 | 依赖 |
|---|---|---|
| [`interp/`](interp/) | 给 webm 补帧（24 → 48/72/90/120 fps，**保留透明通道**）+ 音频快修（去闷 / 响度 / 裁静音 / 降噪） | `ffmpeg`、`rife-ncnn-vulkan`（工具自带自检会告诉你缺什么） |

每个工具目录里都有自己的 `README.md`、`config.json`、一键自检和保姆级说明书，**不共用运行环境**。
装了别的工具不会互相影响，删掉一个也不影响另一个。

## 约定

```text
<工具名>/
  README.md        功能、用法、实测数据
  config.json      唯一需要改的配置文件（留空 = 自动探测）
  一键运行脚本      .bat / .sh / .command 三端
  自检/            环境检查，先跑这个再报 bug
  docs/            实测记录与踩坑
```

## 通用注意

- 这些工具都**只处理本地文件**，不上传、不联网（自检会去 GitHub 查 rife 的 release 地址，仅在你主动点开时）；
- 输出默认落在工具目录的 `output/`；
- 大文件（视频 / 模型 / 打包产物）一律不进仓库。
